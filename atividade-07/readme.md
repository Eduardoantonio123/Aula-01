Erro 1 — Idioma da página
A tag <html> estava sem o atributo lang, que informa ao navegador o idioma utilizado na página.
Erro 2 — Posição do título
A tag <title> estava fora do <head>, mas deve ficar dentro dele para definir corretamente o título da aba do navegador.
Erro 3 — Fechamento do título principal
A tag <h1> não estava fechada, podendo causar problemas na interpretação da estrutura HTML.
Erro 4 — Fechamento do documento
Faltava a tag </html> no final do código para fechar o elemento principal do documento.
