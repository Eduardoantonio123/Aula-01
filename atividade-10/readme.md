Quando o usuário digita rotamineira.com.br no navegador, o DNS localiza o endereço IP correspondente ao domínio. Em seguida, o navegador envia uma requisição HTTP ao servidor solicitando a página inicial (index.html). O servidor recebe a requisição, localiza o arquivo e envia uma resposta com o status 200 OK, acompanhado do conteúdo HTML. Por fim, o navegador interpreta o código recebido e apresenta a página na tela do usuário.
